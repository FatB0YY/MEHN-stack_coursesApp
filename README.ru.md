# Интернет-магазин курсов — стек MEHN

Серверное веб-приложение — магазин образовательных курсов на стеке MEHN: **M**ongoDB, **E**xpress, **H**andlebars, **N**ode.js. Основное внимание в проекте уделено бэкенду — аутентификации, безопасности и работе с данными; за фронтенд отвечает серверная шаблонизация на Handlebars.

## Возможности

- Каталог курсов со страницами деталей и редактированием
- Корзина и оформление заказа
- Сессионная аутентификация через cookies, хранение сессий в MongoDB
- Защита роутов: доступ только для авторизованных пользователей
- CSRF-защита запросов, изменяющих состояние
- Восстановление пароля по почте с токенами ограниченного срока действия
- Валидация всех входящих данных на стороне сервера
- Разграничение прав доступа по владельцу курса
- Загрузка изображений для обложек курсов

## Архитектура

| Папка | Назначение |
| --- | --- |
| `routes` | Роутеры Express, по одному на ресурс |
| `models` | Схемы и модели Mongoose |
| `middleware` | Проверка авторизации, валидация, загрузка файлов, обработка ошибок |
| `pages` | Шаблоны Handlebars, layout'ы и партиалы |
| `emails` | Шаблоны писем для регистрации и восстановления пароля |
| `utils` | Общие хелперы |
| `public` | Статика, отдаваемая браузеру |
| `images` | Загруженные изображения курсов |

`index.js` собирает Express-приложение: цепочку middleware, сессии, роутеры и подключение к базе.

## Стек

Node.js, Express, MongoDB с Mongoose, Handlebars, express-session с connect-mongodb-session, csurf, multer, SendGrid.

## Запуск

Нужны Node.js и экземпляр MongoDB (подойдёт бесплатный кластер Atlas).

    git clone https://github.com/FatB0YY/MEHN-stack_coursesApp.git
    cd MEHN-stack_coursesApp
    npm install

Скопируйте `keys/index.example.js` в `keys/index.js` и заполните своими значениями:

    MONGODB_URI      — строка подключения к MongoDB
    SESSION_SECRET   — любая случайная строка
    SENDGRID_API_KEY — для писем восстановления пароля
    BASE_URL         — адрес приложения, например http://localhost:3000

Затем запустите сервер:

    npm start
